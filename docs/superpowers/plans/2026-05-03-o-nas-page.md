# O nás Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a static "O nás" (About Us) page at `/o-nas` with 7 sections matching the O-V1 wireframe.

**Architecture:** Static React components in `src/components/about/`, composed by a route at `src/app/(frontend)/o-nas/page.tsx`. Reuses `TrustStrip` from homepage (refactored to accept props). All images use `ImagePlaceholder`.

**Tech Stack:** Next.js App Router, Tailwind CSS, shadcn/ui (Card, Button, Badge, Separator), @tabler/icons-react
